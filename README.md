# Volei Core

Site institucional do Volei Core, construído com HTML5, CSS3, JavaScript, React e Vite.

## Desenvolvimento

Instale as dependências e inicie o servidor local:

```sh
npm install
npm run dev
```

Para gerar a versão de produção:

```sh
npm run build
npm run preview
```

Os planos e preços ficam em `src/data/plans.js`. Os componentes da interface estão em `src/components/`.
